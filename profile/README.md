### Equinox is an operating system independently developed by enthusiasts for experimental, hobby, or portfolio purposes. While the operating system is under active development, *using it on your own computer is not recommended, and more likely, impossible*. We welcome any assistance, including ideas, bug fixes, or PR requests.

EquinoxOS could get discontinued but @ewasion137 will try to commit as much as he wants and can. The Equinox-Collective will still make other program besides the OS.
